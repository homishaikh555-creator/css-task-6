CSS Combinators

Understand how HTML elements relate to each other.

What is a combinator?

A CSS combinator joins selectors and describes the relationship between elements in the HTML document. It helps select elements by their position in the page structure.

1. Descendant combinator — space

.box p selects every paragraph anywhere inside .box, including nested paragraphs.

Direct paragraph: selected

Nested paragraph: also selected

Outside paragraph: not selected

.box p { color: green; }

2. Child combinator — >

.box > p selects only paragraphs that are direct children of .box.

Direct paragraph: selected

Nested paragraph: not selected

.box > p { color: green; }

3. Adjacent sibling combinator — +

h3 + p selects the first paragraph immediately after an h3, when both share the same parent.

Heading

Immediately following paragraph: selected

Next paragraph: not selected

h3 + p { color: green; }

4. General sibling combinator — ~

h3 ~ p selects all paragraphs after an h3 that share the same parent. They do not need to be next to the heading.

Heading

First following paragraph: selected

Another element in between

Later paragraph: also selected

h3 ~ p { color: green; }

Quick comparison

CombinatorSymbolMeaning
DescendantspaceAny matching element inside
Child>Direct children only
Adjacent sibling+Immediately next matching sibling
General sibling~All later matching siblings

Conclusion

Use a space for descendants, > for direct children, + for the immediately following sibling, and ~ for all following matching siblings.
